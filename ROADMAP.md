# План разработки Bottleneck3D

## Цель MVP

Доказать, что по уже нарезанному G-code можно локально и достаточно понятно
ответить на первый вопрос, а через Orca-плагин постепенно перейти ко второму и
третьему:

1. Почему этот уже сгенерированный G-code печатается именно столько.
2. Какие лимиты профиля Orca сформировали этот план печати.
3. Как изменится оценка времени, если переслайсить/пересчитать план под
   виртуально изменённые возможности принтера.

Первый MVP принимает G-code. STL и 3MF не содержат готовой траектории и сами по
себе недостаточны для такого диагноза: для них позже понадобится интеграция со
слайсером или его движком.

Важно: готовый G-code — это уже оптимизированный план под текущий профиль, а не
полное описание возможностей принтера. Поэтому веб-MVP без данных Orca не должен
обещать точный выигрыш от покупки железа.

Основная интеграция — нативный Python-плагин OrcaSlicer. Веб-приложение остаётся
самостоятельным интерфейсом и fallback для других слайсеров. Подробные границы
компонентов описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## Критерии точности

До рекомендации покупки железа расчёт должен быть проверен минимум на:

- короткой детали с большим числом разгонов;
- большой детали с высоким объёмным потоком;
- мелких слоях с замедлением для охлаждения;
- одинаковой модели из OrcaSlicer, PrusaSlicer и Cura;
- Klipper и Marlin;
- фактическом времени печати, а не только прогнозе слайсера.

Рекомендация не показывается как достоверная, если файл использует пока
неподдерживаемые команды или оценка расходится с эталонным временем выше
заданного допуска.

## Решения, которые нужно подтвердить

- Минимальная версия OrcaSlicer: latest stable или обязательный legacy fallback.
- Открывать панель после slicing автоматически или только по кнопке.
- Нужно ли в первой версии подключение к Moonraker/Klipper только для чтения,
  чтобы сверять firmware defaults, если Orca/G-code их не раскрывают.
- Приоритет прошивок: Klipper / Marlin.
- Первый язык интерфейса: только русский или сразу RU/EN.
- Первый рынок каталога железа: Беларусь или международные магазины.
