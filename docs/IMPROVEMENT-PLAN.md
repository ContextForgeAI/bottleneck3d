# Bottleneck3D — план улучшений

Состояние на 2026-10-21: веб-приложение (4 вкладки, RU/EN, расчёт в Web Worker),
плагин Orca 0.3.0 (вкладка + окно, авто-приём G-code и пресетов), совпадение с
оценщиками Orca 2.4 / PrusaSlicer ≈0.1%, с Orca 2.5-alpha (Klipper) +3.8%.

Главная ценность продукта — **доверие к числу** и ответ на вопрос «что купить /
что поменять, чтобы печатать быстрее, и сколько я на этом выиграю». Всё ниже
упорядочено по этому критерию.

---

## P1 — киллер-фичи

### 1. «Бесплатные апгрейды» — что даёт прошивка, а не покупка
Через Moonraker (только чтение) взять из `printer.cfg`: `max_accel`,
`square_corner_velocity`, результат input shaper (`recommended max_accel`),
`max_velocity`. Показать:

> Ваш shaper разрешает 7 800 мм/с², в профиле стоит 2 500 → **−2 ч 18 мин на этой
> модели бесплатно**. Качество по шейперу сохранится.

Это самое ценное для владельцев Voron/Klipper: большинство печатает с ускорениями
в 2–3 раза ниже возможных.

### 2. Тепловая карта траектории («где именно тормозит»)
2D-вид слоя (canvas/WebGL) с раскраской каждого сегмента:
зелёный — идёт на заданной скорости, синий — не успевает разогнаться,
оранжевый — упёрся в хотэнд, серый — холостой. Ползунок слоя + проигрывание
(анимированная точка-голова с реальной скоростью). Сразу видно: «на мелких
зубцах fuzzy skin голова никогда не выходит на 200 мм/с».

### 3. Настоящий reslice-what-if через Orca CLI
Сейчас what-if пересчитывает **ту же** траекторию. Плагин может в фоне
нарезать вариант (ускорение ×2, поток ×1.5) через `orca-slicer --slice` и
показать **реальную** оценку Orca рядом с нашей. Дальше — оптимизатор:
перебор accel/speed/flow с ограничениями качества (внешний периметр ≤ N мм/с,
ускорение ≤ shaper) → «лучший профиль под эту модель» с кнопкой «применить к
пресету».

### 4. Цена печати и окупаемость апгрейда (BYN)
Электричество (BYN/кВт·ч, мощность принтера), пластик (BYN/кг из пресета),
износ. «Эта печать стоит 4.3 BYN». Для апгрейда: «CHT за 45 BYN сэкономит
6 ч/мес при вашей нагрузке → окупится за N месяцев». Ссылки на onliner.by /
Wildberries.by / местные магазины (с явной пометкой реферальных).

### 5. Гараж принтеров
Несколько профилей (Voron 2.4, Ghost 6): «на каком принтере эта модель
напечатается быстрее и почему». Пересчёт одного G-code под чужие лимиты.

### 6. Риски качества рядом со скоростью
Предупреждать, когда what-if уходит в опасную зону: поток > 85% хотэнда
(недоэкструзия), ускорение выше shaper (ringing), слой короче минимального
времени охлаждения, нависания на высокой скорости. Ускорение без потери
качества — главный страх пользователя.

## P2 — удобство и распространение

- Отчёт-картинка для форумов/Telegram: модель, время, разбивка, лучший апгрейд.
- История: каждый слайс из Orca сохраняется → тренд «стало быстрее после
  смены профиля».
- Пакетный режим: папка G-code → таблица (что тормозит в каждой модели).
- Мультиматериал: время на смену инструмента, prime tower, purge.
- Планировщик ночной очереди: уложить несколько печатей в окно 23:00–07:00.
- PWA/офлайн, подписанный wheel, автообновление плагина.
- Онбординг «за 30 секунд»: первая загрузка показывает подсказки на живых данных.

## Порядок работ

1. P0.2 (замер погрешности) → P0.1 (порт Klipper-планировщика) → повторный замер.
2. P1.1 (Moonraker, бесплатные апгрейды) — максимальная польза при малом объёме.
3. P1.2 (тепловая карта) — максимальная наглядность.
4. P1.3 (reslice + оптимизатор) — использует наработки теста P0.2.
5. P1.4–P1.6, затем P2.
